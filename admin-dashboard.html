Import clients

        
Header row required. Accepts .csv or .xlsx / .xls:

        
name,email,phone,address,gstin,notes
Aditi Sharma,aditi@example.com,9876543210,"12 MG Road, Surat",24AAAAA0000A1Z5,VIP

        

          
          
        

        

      


      

        
Import products

        
Header row required. storeType is one of grocery, restaurant, retail, other. Tax slab can be percentage (e.g. 12) or slab name (e.g. GST 12%). Accepts .csv or .xlsx / .xls:

        
name,brand,storeType,category,unit,price,cost,stock,lowStockLimit,sku,barcode,hsnCode,taxSlab,taxPercent,notes,expiryDate
